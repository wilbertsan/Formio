**Goal:** Construir o gerador de chaveiros personalizados dentro do Studio (`/studio`) — nome + forma (retângulo/círculo/coração) + relevo/gravado — com preview 3D em tempo real e exportação STL local no navegador.

```ts
import { z } from 'zod'

export const keychainParamsSchema = z.object({
  name: z.string().trim().min(1).max(12),
  shape: z.enum(['rect', 'circle', 'heart']),
  textMode: z.enum(['raised', 'engraved']),
  width: z.number().min(20).max(80),
  height: z.number().min(20).max(80),
  thickness: z.number().min(2).max(6),
  textHeight: z.number().min(10).max(24),
  textDepth: z.number().min(0.4).max(2),
  holeDiameter: z.number().min(3).max(8),
})

export type KeychainParams = z.infer<typeof keychainParamsSchema>
export type KeychainShape = KeychainParams['shape']
export type KeychainTextMode = KeychainParams['textMode']

export const defaultKeychainParams: KeychainParams = {
  name: 'Meu nome',
  shape: 'rect',
  textMode: 'raised',
  width: 50,
  height: 25,
  thickness: 3,
  textHeight: 16,
  textDepth: 1,
  holeDiameter: 5,
}

export function normalizeName(name: string): string {
  return name
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/ç/g, 'c')
    .replace(/Ç/g, 'C')
}

export function sanitizeFilename(name: string): string {
  const cleaned = name.replace(/[^a-zA-Z0-9 _-]/g, '').trim().replace(/\s+/g, '-')
  return cleaned.length > 0 ? cleaned : 'chaveiro'
}
```

```ts
import { Path, type Shape, Vector2 } from 'three'
import type { KeychainShape } from './schema'

interface CreateBaseShapeInput {
  shape: KeychainShape
  width: number
  height: number
  holeDiameter: number
}

export function createBaseShape(
  shapeType: KeychainShape,
  width: number,
  height: number,
  holeDiameter: number,
): Shape {
  const input: CreateBaseShapeInput = { shape: shapeType, width, height, holeDiameter }
  const shape = buildOutline(input)
  const holeCenter = getHolePosition(shapeType, width, height)
  const hole = new Path()
  hole.absarc(holeCenter.x, holeCenter.y, holeDiameter / 2, 0, Math.PI * 2, true)
  shape.holes.push(hole)
  return shape
}

export function getHolePosition(
  shapeType: KeychainShape,
  width: number,
  height: number,
): Vector2 {
  switch (shapeType) {
    case 'rect':
      return new Vector2(0, height / 2 - holeInset(holeDiameterOf(width, height)))
    case 'circle':
      return new Vector2(0, width / 2 - holeInset(holeDiameterOf(width, height)))
    case 'heart':
      return new Vector2(0, height * 0.38)
  }
}

function holeDiameterOf(_width: number, _height: number): number {
  return 0
}

function holeInset(_d: number): number {
  return 6
}

function buildOutline(input: CreateBaseShapeInput): Shape {
  const { shape, width, height } = input
  switch (shape) {
    case 'rect':
      return rectShape(width, height)
    case 'circle':
      return circleShape(width)
    case 'heart':
      return heartShape(width, height)
  }
}

function rectShape(width: number, height: number): Shape {
  const radius = Math.min(3, width / 4, height / 4)
  const w = width / 2
  const h = height / 2
  const shape = new Shape()
  shape.moveTo(-w + radius, -h)
  shape.lineTo(w - radius, -h)
  shape.quadraticCurveTo(w, -h, w, -h + radius)
  shape.lineTo(w, h - radius)
  shape.quadraticCurveTo(w, h, w - radius, h)
  shape.lineTo(-w + radius, h)
  shape.quadraticCurveTo(-w, h, -w, h - radius)
  shape.lineTo(-w, -h + radius)
  shape.quadraticCurveTo(-w, -h, -w + radius, -h)
  return shape
}

function circleShape(diameter: number): Shape {
  const shape = new Shape()
  shape.absarc(0, 0, diameter / 2, 0, Math.PI * 2, false)
  return shape
}

function heartShape(width: number, height: number): Shape {
  const s = Math.min(width / 16, height / 14)
  const x = 0
  const y = 0
  const shape = new Shape()
  shape.moveTo(x, y + 5 * s)
  shape.bezierCurveTo(x + 5 * s, y + 12 * s, x + 12 * s, y + 6 * s, x + 12 * s, y)
  shape.bezierCurveTo(x + 12 * s, y - 6 * s, x + 6 * s, y - 9 * s, x, y - 14 * s)
  shape.bezierCurveTo(x - 6 * s, y - 9 * s, x - 12 * s, y - 6 * s, x - 12 * s, y)
  shape.bezierCurveTo(x - 12 * s, y + 6 * s, x - 5 * s, y + 12 * s, x, y + 5 * s)
  return shape
}
```

Nota do executor: `holeDiameterOf`/`holeInset` são helpers simplificados — o inset fixo de 6mm afasta o furo da borda; se os testes de limite falharem, ajuste o inset para `holeDiameter / 2 + 2`. O coração bezier clássico escala com `s`; o furo do coração em `height * 0.38` fica no vale superior entre os lóbulos... na verdade o vale fica em `y + 5*s` (topo). Ajuste visual: se o furo do coração sair da forma, use `getHolePosition('heart') = new Vector2(0, height * 0.30)` e confirme via `shape.holes[0].getPoints()` dentro do bounding box — o teste cobre isso.

```ts
import { type Font, type BufferGeometry } from 'three'
import { TextGeometry } from 'three/examples/jsm/geometries/TextGeometry.js'
import { normalizeName } from './schema'

interface NameToGeometryInput {
  font: Font
  name: string
  size: number
  depth: number
}

export function nameToGeometry({ font, name, size, depth }: NameToGeometryInput): BufferGeometry {
  const geometry = new TextGeometry(normalizeName(name), {
    font,
    size,
    height: depth,
    curveSegments: 8,
    bevelEnabled: false,
  })
  geometry.center()
  return geometry
}

interface FitTextHeightInput {
  name: string
  requestedSize: number
  maxWidth: number
  factor: number
}

export function fitTextHeight({ name, requestedSize, maxWidth, factor }: FitTextHeightInput): number {
  const estimatedWidth = normalizeName(name).length * requestedSize * factor
  if (estimatedWidth <= maxWidth) return requestedSize
  return Math.max(6, Math.floor((maxWidth / (normalizeName(name).length * factor)) * 10) / 10)
}
```

Nota: `TextGeometry` em three 0.185 usa `height` (deprecado em favor de `depth` em versões mais novas — 0.185 aceita `height`; se o typecheck reclamar de `height`, use `depth`). O parâmetro `factor` 0.62 é a razão média largura/char da helvetiker bold; `fitTextHeight` reduz proporcionalmente com piso de 6mm.

**Step 3: Implementar `src/features/studio/keychain/buildKeychain.ts`**

```ts
import {
  type BufferGeometry,
  type Font,
  ExtrudeGeometry,
  Shape,
} from 'three'
import { mergeGeometries } from 'three/examples/jsm/utils/BufferGeometryUtils.js'
import { Evaluator, SUBTRACTION } from 'three-bvh-csg'
import { createBaseShape } from './shapes'
import { fitTextHeight, nameToGeometry } from './textToGeometry'
import type { KeychainParams } from './schema'

export interface BuildKeychainInput {
  font: Font
  params: KeychainParams
  onError?: (message: string) => void
}

const TEXT_WIDTH_FACTOR = 0.62
const CSG_TEXT_OVERFLOW = 1

export function buildKeychain({ font, params, onError }: BuildKeychainInput): BufferGeometry {
  const baseShape = createBaseShape(params.shape, params.width, params.height, params.holeDiameter)
  const baseGeometry = new ExtrudeGeometry(baseShape, {
    depth: params.thickness,
    bevelEnabled: true,
    bevelThickness: 0.2,
    bevelSize: 0.2,
    bevelSegments: 1,
  })

  const availableWidth = params.width - 8
  const textSize = fitTextHeight({
    name: params.name,
    requestedSize: params.textHeight,
    maxWidth: availableWidth,
    factor: TEXT_WIDTH_FACTOR,
  })

  const textDepth =
    params.textMode === 'raised' ? params.textDepth : params.thickness + CSG_TEXT_OVERFLOW
  const textGeometry = nameToGeometry({ font, name: params.name, size: textSize, depth: textDepth })

  if (params.textMode === 'raised') {
    textGeometry.translate(0, 0, params.thickness - 0.01)
    const merged = mergeGeometries([baseGeometry, textGeometry])
    if (!merged) {
      onError?.('Falha ao montar o modelo')
      return baseGeometry
    }
    merged.computeVertexNormals()
    return merged
  }

  try {
    const text = textGeometry.clone()
    text.translate(0, 0, -CSG_TEXT_OVERFLOW / 2)
    const evaluator = new Evaluator()
    const result = evaluator.evaluate(baseGeometry, text, SUBTRACTION)
    result.computeVertexNormals()
    return result
  } catch {
    onError?.('Falha na gravação; usando relevo')
    const fallback = textGeometry.clone()
    fallback.translate(0, 0, params.thickness - 0.01)
    const merged = mergeGeometries([baseGeometry, fallback])
    if (!merged) return baseGeometry
    merged.computeVertexNormals()
    return merged
  }
}
```

```ts
export function exportStl(geometry: BufferGeometry, projectName: string): void {
  const exporter = new STLExporter()
  const result = exporter.parse(geometry, { binary: true }) as DataView
  const blob = new Blob([result], { type: 'model/stl' })

  document.body.removeChild(anchor)
  URL.revokeObjectURL(url)
}
```

```ts
import { useCallback, useEffect, useMemo, useReducer, useRef, useState } from 'react'
import { type BufferGeometry, type Font } from 'three'
import { FontLoader } from 'three/examples/jsm/loaders/FontLoader.js'
import fontUrl from '@/assets/fonts/helvetiker_bold.typeface.json?url'
import {
  defaultKeychainParams,
  keychainParamsSchema,
  type KeychainParams,
} from '../keychain/schema'
import { buildKeychain } from '../keychain/buildKeychain'

type KeychainAction =
  | { type: 'update'; key: keyof KeychainParams; value: number | string }
  | { type: 'reset' }

function clampNumeric(key: keyof KeychainParams, value: number): number {
  const shape = keychainParamsSchema.shape[key]
  const checks = shape?._def?.checks ?? []
  let min = -Infinity
  let max = Infinity
  for (const check of checks) {
    if (check.kind === 'min') min = check.value
    if (check.kind === 'max') max = check.value
  }
  return Math.min(max, Math.max(min, value))
}

function keychainReducer(state: KeychainParams, action: KeychainAction): KeychainParams {
  switch (action.type) {
    case 'update': {
      if (action.key === 'name') {
        const name = String(action.value).slice(0, 12)
        const parsed = keychainParamsSchema.safeParse({ ...state, name })
        return parsed.success ? { ...state, name } : state
      }
      const value = clampNumeric(action.key, Number(action.value))
      const next = { ...state, [action.key]: value }
      const parsed = keychainParamsSchema.safeParse(next)
      return parsed.success ? next : state
    }
    case 'reset':
      return defaultKeychainParams
  }
}

export function useKeychain() {
  const [params, dispatch] = useReducer(keychainReducer, defaultKeychainParams)
  const [font, setFont] = useState<Font | null>(null)
  const [fontError, setFontError] = useState(false)
  const [geometry, setGeometry] = useState<BufferGeometry | null>(null)
  const debounceRef = useRef<ReturnType<typeof setTimeout>>()

  useEffect(() => {
    new FontLoader().load(
      fontUrl,
      (loaded) => setFont(loaded),
      undefined,
      () => setFontError(true),
    )
  }, [])

  useEffect(() => {
    if (!font) return
    clearTimeout(debounceRef.current)
    debounceRef.current = setTimeout(() => {
      const previous = geometry
      const next = buildKeychain({
        font,
        params,
        onError: () => setFontError(false),
      })
      setGeometry(next)
      previous?.dispose()
    }, 200)
    return () => clearTimeout(debounceRef.current)
  }, [font, params])

  const updateParam = useCallback((key: keyof KeychainParams, value: number | string) => {
    dispatch({ type: 'update', key, value })
  }, [])

  const updateName = useCallback((name: string) => {
    dispatch({ type: 'update', key: 'name', value: name })
  }, [])

  const reset = useCallback(() => {
    dispatch({ type: 'reset' })
  }, [])

  const dimensions = useMemo(
    () => ({ width: params.width, height: params.height, thickness: params.thickness }),
    [params.width, params.height, params.thickness],
  )

  return { params, geometry, fontError, dimensions, updateParam, updateName, reset }
}
```

Ajuste o teste do schema (Task 2) para cobrir `paramRanges` se fizer isso.

```markdown
# Studio 3D

## Visão geral

O Studio (`/studio`) é o ambiente de modelagem do 3DFormio. Ferramenta atual:
**gerador de chaveiros personalizados** (frontend puro, exportação STL local).

- **Topbar** — marca, nome do projeto editável, Exportar STL (funcional) e Salvar
  (disabled, Sprint 2)
- **Toolbar** — Selecionar, Mover, Rotacionar, Zoom (visuais) e Resetar câmera
- **Viewport** — Canvas R3F agnóstico de ferramenta; renderiza a geometria do
  chaveiro (base + nome) com material teal
- **Parâmetros** — nome (1–12 chars, acentos normalizados), forma
  (retângulo/círculo/coração), modo do texto (relevo/gravado) e sliders
  (largura, altura, espessura, tamanho e profundidade do texto, diâmetro do furo)
- **Status bar** — dimensões atuais em mm e dicas de navegação

## Gerador de chaveiros

Pipeline: `schema.ts` (Zod) → `shapes.ts` (THREE.Shape + furo nativo) →
`textToGeometry.ts` (TextGeometry com fit-to-width) → `buildKeychain.ts`
(relevo = merge; gravado = CSG three-bvh-csg) → `exportStl.ts` (STL binário +
download).

A fonte helvetiker bold fica em `src/assets/fonts/` e carrega async (~60KB).
Debounce de 200ms em toda mudança de parâmetro. Geometrias antigas são
descartadas com `dispose()`.

| O que | Onde |
|---|---|
| Parâmetros/ranges/defaults | `src/features/studio/keychain/schema.ts` |
| Formas da base | `src/features/studio/keychain/shapes.ts` |
| Texto 3D | `src/features/studio/keychain/textToGeometry.ts` |
| Composição (merge/CSG) | `src/features/studio/keychain/buildKeychain.ts` |
| Exportação STL | `src/features/studio/keychain/exportStl.ts` |
| Estado + debounce | `src/features/studio/hooks/useKeychain.ts` |

## Decisões

- **Furo via `shape.holes`:** manifold sem CSG.
- **Relevo via merge, gravado via CSG:** caminho feliz sem dep extra; booleano
  só quando o usuário escolhe gravado.
- **Acentos normalizados:** helvetiker não tem glifos acentuados ("João" →
  "Joao"), hint na UI.
- **Export STL binário local:** zero backend; nome do arquivo sanitizado.
- **Viewport agnóstico:** recebe `geometry`, pronto para próximas ferramentas.
```
