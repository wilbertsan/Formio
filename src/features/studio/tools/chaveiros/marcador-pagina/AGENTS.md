# Ferramenta: Marcador de Página

## Status

Planejada.

## Objetivo

Gerar marcadores de página 3D finos com texto e/ou formas decorativas.

## Parâmetros previstos

- Formato: retangular, redondo, personalizado
- Espessura: 1–2mm
- Comprimento: 50–150mm
- Largura: 30–50mm
- Texto: conteúdo, fonte, tamanho
- Decoração: furo, laço, formato de ponta

## Regras do domínio

- Espessura fina (1–2mm) para não abrir demais o livro
- Ponta arredondada ou formatada para facilitar inserção
- Texto/decoração em relevo (não gravado — ficaria frágil)

## Fora de escopo

Chaveiros, confeitaria, letreiros, backend.
