# Ferramenta: Placa de Loja

## Status

Planejada.

## Objetivo

Gerar placas de identificação para lojas, eventos e ambientes.

## Parâmetros previstos

- Largura: 100–300mm
- Altura: 50–150mm
- Espessura: 3–8mm
- Texto: nome da loja, slogan (1–3 linhas)
- Formato: retangular, arredondado, personalizado
- Fixação: furos para parafuso, base para mesa, suporte para parede

## Regras do domínio

- Texto grande e legível (altura mínima 5mm)
- Fundo plano para boa adesão de filament
- Furos de fixação: diâmetro 4–6mm, margem 5mm da borda
- Peso: considerar para fixação em parede

## Fora de escopo

Chaveiros, confeitaria, backend.
