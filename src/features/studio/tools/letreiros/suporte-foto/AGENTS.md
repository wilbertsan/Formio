# Ferramenta: Suporte para Foto

## Status

Planejada.

## Objetivo

Gerar suportes/stands para exibir fotos, quadros ou placas pequenas.

## Parâmetros previstos

- Largura da base: 40–100mm
- Profundidade da base: 30–60mm
- Altura do suporte: 50–120mm
- Espessura: 2–4mm
- Ângulo de inclinação: 60–85°
- Slot para foto: largura 1–3mm, profundidade 5–15mm

## Regras do domínio

- Estabilidade: base antideslizante ou larga
- Slot para encaixe da foto/quadro
- Ângulo ajustável ou fixo (fixo = mais simples)
- Compatível com fotos 10×15, 13×18, 15×20cm

## Fora de escopo

Chaveiros, confeitaria, backend.
