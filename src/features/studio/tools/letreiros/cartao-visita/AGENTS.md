# Ferramenta: Cartão de Visita

## Status

Planejada.

## Objetivo

Gerar cartões de visita 3D com texto e layout personalizado.

## Parâmetros previstos

- Largura: 50–90mm
- Altura: 30–60mm
- Espessura: 1–3mm
- Texto: nome, cargo, contato (1–3 blocos)
- Fonte: normal, bold, serif
- Layout: centralizado, à esquerda

## Regras do domínio

- Texto em relevo para leitura tátil
- Margem mínima de 3mm
- Cantos arredondados opcionais
- Formato padrão de cartão (proporção ~3:2)

## Fora de escopo

Chaveiros, confeitaria, backend.
