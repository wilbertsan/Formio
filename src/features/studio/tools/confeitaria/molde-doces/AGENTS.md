# Ferramenta: Molde para Cortar Doces

## Status

Planejada.

## Objetivo

Gerar moldes/cortadores para massas, fondant e biscoitos com formatos personalizados.

## Parâmetros previstos

- Formato: circular, retangular, estrela, coração, personalizado
- Diâmetro/largura: 30–80mm
- Altura da parede: 15–60mm
- Espessura da parede: 0.8–2mm
- Margem de corte: 0.2–0.5mm

## Regras do domínio

- Arestas de corte afiadas mas seguras
- Parede uniforme para corte consistente
- Base aberta (cortador) ou fechada (recorte)
- STL manifold sem self-intersections

## Fora de escopo

Chaveiros, letreiros, backend.
