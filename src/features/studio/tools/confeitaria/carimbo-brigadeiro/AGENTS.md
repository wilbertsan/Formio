# Ferramenta: Carimbo para Brigadeiro

## Status

Planejada.

## Objetivo

Gerar carimbos para marcar brigadeiros e doces com textos ou formatos.

## Parâmetros previstos

- Formato: circular, quadrado
- Diâmetro: 10–30mm
- Altura do carimbo: 5–20mm
- Profundidade do relevo: 0.5–2mm
- Texto/Formato: conteúdo, fonte, tamanho

## Regras do domínio

- Relevo negativo (o que é gravado aparece no doce)
- Superfície plana de contato
- Altura mínima para承 grip durante uso
- Arebaseada para não marcar a superfície de apoio

## Fora de escopo

Chaveiros, letreiros, backend.
