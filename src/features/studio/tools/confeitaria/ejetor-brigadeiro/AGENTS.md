# Ferramenta: Ejetor de Brigadeiro

## Status

Planejada.

## Objetivo

Gerar ejetor/molda para desenformar brigadeiros com formato uniforme.

## Parâmetros previstos

- Formato: semiesfera, cilindro com base
- Diâmetro: 25–40mm
- Altura: 15–30mm
- Espessura da parede: 1–2mm
- Superfície interna: lisa ou com textura

## Regras do domínio

- Superfície interna lisa para facilitar desenformagem
- Borda arredondada para não marcar o doce
- Parede fina o suficiente paraFlex mas rígida o suficiente para ejeção
- Base plana para apoio

## Fora de escopo

Chaveiros, letreiros, backend.
