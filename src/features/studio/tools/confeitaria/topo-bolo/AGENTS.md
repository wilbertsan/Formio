# Ferramenta: Topo de Bolo

## Status

Planejada.

## Objetivo

Gerar toppers decorativos para bolo com texto e formatos personalizados.

## Parâmetros previstos

- Formato: circular, retangular, personalizado (contorno)
- Largura: 50–120mm
- Altura: 30–80mm
- Espessura: 2–4mm
- Texto: conteúdo, fonte, tamanho
- Suporte: palito ou base para fixação no bolo

## Regras do domínio

- Peça plana com suporte vertical para fixação
- Texto/template em relevo ou corte (silhueta)
- Base de fixação: furo para palito ou pé de encaixe
- Peso leve para não tombas o bolo

## Fora de escopo

Chaveiros, letreiros, backend.
